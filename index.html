01

基于知识图谱的农业大模型评测方法

面向农业大模型评测场景，从明白卡和专家知识中抽象实体、关系、属性与约束规则， 构建可迁移的农业多学科 Schema，并围绕语料清洗、结构化抽取、图谱导入和可视化查询 搭建可复用流程。

230 实体类型 506 关系类型 555 属性字段 30M+ 清洗语料

采用 GPT-4o 两阶段 Prompt 策略：先依据 Schema 约束输出实体，再结合关系集合与实体对约束生成三元组。 Neo4j 图谱包含 3,275 个实体节点和 13,055 条语义关系，覆盖作物、病虫害、技术措施等核心类型。

  • Knowledge Graph
  • GPT-4o
  • Neo4j

02

OpenVLA for Drive 动作决策分支

围绕 OpenVLA for Drive 中的 action branch 独立搭建实验环境，先验证从 BEV 感知特征到驾驶动作分类的关键模块， 为后续完整视觉-语言-动作自动驾驶模型打基础。

BEV features LightBEVQFormer Action Classifier 12-class Action

当前采用 12 类“纵向控制 + 横向控制”组合动作标签，包括 maintain、accelerate、decelerate、stop、 turn_left / turn_right 及其组合动作。已完成 baseline、多任务 head、weighted CE、label smoothing、 warmup、balanced softmax 等训练策略对比，并推进 rich_text 场景语义融合。

62.13% Exact Acc 90% 左右横向准确率 29.43% Macro F1 69.48% Blended Score

03

基于 GraphRAG 的古建筑知识网络

面向古建筑历史资料数字化利用，设计建筑实体与关系 Schema，完成文本清洗、关系抽取、 结果后处理、CSV/JSON 导出、知识网络构建和查询交互测试。

文本处理流程拆为三阶段：先进行句子补全和指代消解，再结合规则与大模型按固定 Schema 抽取关系， 最后做标签规范化、别名归并、重复关系合并、逻辑验证和 needs_review 标记。图谱覆盖 153 栋建筑和 671 条关系 / 属性记录，并探索图片特征与本地向量检索的多模态匹配。
